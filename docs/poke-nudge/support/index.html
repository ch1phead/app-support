PokeNudge

Support

PokeNudge is a reminder companion for Pokémon GO. It keeps your task list, Buddy check-in routine, notifications, and timer tools together on your devices.

Quick troubleshooting

  • Reminders are not appearing: Open Settings → Notifications → PokeNudge and allow notifications, sounds, and time-sensitive alerts as desired. Confirm the task is enabled in PokeNudge.
  • The Live Activity or Dynamic Island timer is missing: Turn on Live Activities in Settings → Apps → PokeNudge, then start a task marked “Do Now.” Live Activities are supported on compatible iPhone models.
  • The timer is not updating: Open PokeNudge once, make sure the task is still active, and check that Low Power Mode or Focus settings are not preventing alerts. The timer can continue on the Lock Screen or Dynamic Island after you leave the app.
  • Apple Watch is not up to date: Make sure the Watch app is installed, both devices are nearby and paired, and PokeNudge has been opened on the iPhone recently. Watch data syncs when WatchConnectivity is available.
  • Imported tasks are not loading: Check the URL and network connection, then try importing the CSV or JSON file again. Remote task packs are optional; the bundled tasks work without an internet connection.
  • Pokémon GO did not open: PokeNudge can open Pokémon GO when it is installed. If it is unavailable, launch Pokémon GO manually and return to PokeNudge to continue the timer.

What PokeNudge can do

  • Organize daily, missable, event, raid, research, friendship, and Buddy tasks.
  • Schedule one-time, daily, and weekly reminders with optional time-sensitive alerts.
  • Start a Buddy timer from the app, a Home Screen shortcut, Siri, or an App Intent.
  • Show an active timer in a Live Activity, Dynamic Island, Lock Screen, widget, Apple Watch app, and Watch complications.
  • Import and export task packs as CSV or JSON, including an optional saved remote source URL.

Report a bug or request help

Open a support request on GitHub. Include your device model, iOS or watchOS version, PokeNudge version, what you expected, and what happened. GitHub issues are public, so please do not include sensitive personal information.

Restaurant Wishlist

Support

Restaurant Wishlist runs as an iMessage app. Open the Messages app drawer, select Restaurant Wishlist, add suggestions, and share the current wishlist with the conversation.

Common fixes

If the app does not appear in Messages, tap the App Store icon in the Messages app drawer and enable Restaurant Wishlist. If a vote update looks stale, share the latest wishlist again.
